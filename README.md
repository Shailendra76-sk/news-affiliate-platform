# 🔥 LootBazaar News - AI Powered News Platform

> Fully automated Hindi/Hinglish news platform with Amazon affiliate integration

## ✅ Features

- 📡 Auto news fetch every 2 hours (8 categories)
- 🤖 AI article generation (Hindi/Hinglish)
- 🔄 Multi-AI fallback system (Groq, Gemini, DeepSeek, Mistral, etc)
- 🛒 Amazon affiliate product integration
- 📘 Facebook auto posting
- 🖼️ Auto image attachment
- 📊 Admin dashboard
- 🌙 Dark mode
- 📱 Mobile responsive
- 🔍 SEO optimized

## 🛠️ Tech Stack

- **Backend**: Python, FastAPI, SQLite
- **Frontend**: HTML, CSS, JavaScript
- **AI**: Groq, Gemini, DeepSeek, Mistral, Cohere
- **Hosting**: Render (backend), Vercel (frontend)
- **Scheduler**: GitHub Actions
